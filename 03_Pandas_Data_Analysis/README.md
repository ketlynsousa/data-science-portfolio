# 🐼 Module 03: Data Analysis with Pandas

This folder contains Jupyter Notebooks, datasets, and practical exercises developed during the **Pandas** courses from Alura's Data Science Career Track.

## 📁 Content Overview

* **`part_1_pandas_fundamentals/`**: Introduction to Pandas, DataFrames, Series, data selection, filtering, and initial exploratory data analysis (EDA).
  * `lessons/`: Main guided project on real estate data (`real_estate_project_pandas.ipynb`).
  * `exercises/`: Hands-on exercises exploring student datasets and machine learning requests.

* **`part_2_pandas_io/`**: Working with different file formats (CSV, JSON, HTML, Database tables) and data import/export techniques.
  * `lessons/`: Notebooks covering step-by-step file loading and manipulation.
  * `exercises/`: Challenges involving varied data formats.
  * `resources/`: Raw data files (JSON, HTML, images) used during exercises and lessons.

* **`part_3_pandas_selecting_and_grouping/`**: Advanced data selection, conditional filtering, grouping operations (`groupby`), and aggregations.
  * `lessons/`: Guided notebooks working with population and emissions datasets (`POP2022_Municipios`, `SEEG10`).
  * `exercises/`: Hands-on challenges applying queries, filtering logic, and summary statistics.
  * `resources/`: Public datasets (Excel files) used for data aggregation and analysis.

* **`part_4_pandas_data_transformation/`**: Data cleaning, wrangling, nested JSON normalization, string manipulation, and type conversions.
  * `lessons/`: Step-by-step notebooks on transforming hospitality and property availability datasets (`lesson_01.ipynb` through `lesson_04.ipynb`).
  * `exercises/`: Practical challenges and a comprehensive challenge project (`challenge_project.ipynb`).
  * `resources/`: Hospitality datasets in JSON format (`dados_hospedagem.json`, `moveis_disponiveis.json`, normalized versions).

* **`part_5_pandas_data_cleaning/`**: Comprehensive data cleaning pipeline, handling missing values, identifying and removing outliers, encoding categorical features (dummies), and exporting processed datasets.
  * `lessons/`: Guided notebooks (`lesson_01.ipynb` through `lesson_05.ipynb`) covering customer churn data preprocessing (`dataset-telecon.json`) and overview documentation.
  * `exercises/`: Practical exercises (`exercise_01.ipynb` through `exercise_04.ipynb`) focusing on missing value handling, outlier detection, and data feature encoding.
  * `resources/`: Telecom customer churn JSON datasets and intermediate preprocessed subsets (normalized, null-removed, outlier-filtered, and dummy-encoded versions).

## 🛠️ Tools & Libraries
* **Language:** Python 3.x
* **Primary Library:** Pandas
* **Environment:** Google Colaboratory (`.ipynb`)
