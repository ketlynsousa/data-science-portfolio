# 🐍 Module 01: Python for Data Science

This folder contains notebooks and practice projects developed during the **Python for Data Science** module from Alura's Data Science Career Track.

## 📁 Content Overview

* **`lessons/`**: Notebooks following the course lectures and theoretical concepts.
  * `lesson1_python_for_datascience.ipynb`: Introduction to Python syntax, variables, Google Colab environment, and basic output.
  * `lesson2_python_for_datascience.ipynb`: Functions, data structures (lists, dictionaries), loops, and exception handling.

* **`practice_projects/`**: Practical exercises and mini-projects applying the learned concepts.
  * `practice_time_lesson_1.ipynb`: Hands-on challenges covering Python fundamentals.
  * `practice_time_lesson_2.ipynb`: Mini-projects focused on data structures and logic.

## 🛠️ Tools & Libraries
* **Language:** Python 3.x
* **Environment:** Google Colaboratory
