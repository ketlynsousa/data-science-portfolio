\# 🗄️ Module 02: SQLite \& SQL Queries



This folder contains SQL scripts, database tables, and practical exercises developed during the \*\*SQLite \& SQL\*\* courses from Alura's Data Science Career Track.



\## 📁 Structure



\* \*\*`part\_1\_sql\_instructions/`\*\*: Introduction to SQL syntax, database creation, table management (`CREATE`, `INSERT`, `UPDATE`, `DELETE`), and data types.

\* \*\*`part\_2\_sql\_queries/`\*\*: Advanced querying techniques including data filtering (`WHERE`, `LIKE`, `IN`), aggregations (`GROUP BY`, `HAVING`), joins, and ordering.



Each section contains:

\* \*\*`lessons/`\*\*: Guided SQL scripts and sample dataset resources used during lectures.

\* \*\*`exercises/`\*\*: Hands-on SQL exercises and mini-projects solving practical database problems.



\## 🛠️ Tools

\* \*\*Database Engine:\*\* SQLite

\* \*\*Environment:\*\* \[SQLite Online](https://sqliteonline.com/) / DBeaver
